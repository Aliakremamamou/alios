Règles de confidentialité d'ALIOS

Dernière mise à jour : 13 novembre 2026.

Données utilisées

ALIOS accède aux données Google du seul compte qui l'a autorisé (agenda, tâches, fichiers Drive ouverts par ALIOS, contacts), uniquement pour les afficher et les modifier à la demande de cet utilisateur.

Stockage

Les données restent sur l'ordinateur de l'utilisateur. Les jetons de connexion y sont chiffrés. ALIOS n'a pas de serveur qui conserve les données Google.

Partage

Les données Google ne sont ni vendues, ni partagées, ni utilisées pour la publicité. L'usage des données reçues des API Google respecte les règles relatives aux données utilisateur des services API Google, y compris les exigences d'utilisation limitée.

Retrait de l'accès

L'utilisateur peut retirer l'accès à tout moment sur myaccount.google.com/permissions.
